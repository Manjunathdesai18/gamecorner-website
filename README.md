## 📌 Project Overview

**GameCorner** is a lightweight, zero-dependency browser portal built with pure HTML5, CSS3, and JavaScript. Designed with two parallel zones:
1. **The Arcade Zone**: Classic puzzle games (2048, Snake, Connect 4, Tic-Tac-Toe, Flip Card).
2. **The Discovery Zone**: Interactive flashcard lessons and quizzes helping toddlers and early students learn animal names, bird species, colors, and shapes.

## 🕹️ Games Catalog

| Game | File Entry | Description |
|:---|:---|:---|
| **2048** | `2048.html` | Tile sliding puzzle to merge numbers and reach the 2048 tile. |
| **Connect 4** | `connect4.html` | Two-player strategy game dropping tokens to connect four in a row. |
| **Snake Classic** | `snakegame.html` | Retro arcade game to guide the snake, eat food, and grow. |
| **Tic-Tac-Toe** | `tictactoc.html` | Classic 3x3 grid game of Xs and Os against a friend or computer. |
| **Flip Card (Memory Match)** | `flipcard.html` | Visual memory challenge matching pairs of hidden cards. |
| **Rock Paper Scissors** | `rps.html` | Quick reflex showdown against random computer hand throws. |
| **Roll The Dice** | `rollthedice.html` | Animated dice roller with randomizer logic. |
| **Coin Flipper** | `flipcoin.html` | Smooth coin toss animation for quick decision making. |
| **Number Guessing** | `numbergame.html` | Clue-based number guessing challenge. |
| **Multiplying Game** | `multiplyinggame.html` | Speed math game practicing times-table multiplication. |
| **Clumsy Bird** | `clumsybird.html` | Tap-to-flap obstacle avoider game testing timing and reflexes. |

## 🚀 How to Run Locally

### Option 1: Direct Browser Launch
Simply double click `home.html` in your file explorer to open it in any modern browser.

### Option 2: Run with a Local Server
```bash
git clone https://github.com/Manjunathdesai18/gamecorner-website.git
cd gamecorner-website

# Using Python
python -m http.server 8080
```
Open `http://localhost:8080/home.html` in your browser.
