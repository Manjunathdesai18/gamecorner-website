GameCorner Website
A modern, responsive web portal for the GameCorner community. This site showcases game reviews, news, and community forums with a sleek, dark-mode-friendly design.

📖 Project Overview
Purpose: Provide an engaging platform for gamers to discover content, share reviews, and discuss trends.
Tech Stack: HTML5, CSS3 (with custom design system), JavaScript (ES6+). No heavyweight frameworks – lightweight and fast.
Design Highlights:
Dark mode with vibrant accent colors.
Glassmorphism UI components.
Subtle micro‑animations for interactivity.
✨ Features
Responsive layout for mobile, tablet, and desktop.
Dynamic navigation with smooth scroll effects.
Integrated comment system (placeholder for future backend).
SEO‑optimized markup with proper heading hierarchy and meta tags.
🚀 Installation
bash

# Clone the repository (if applicable)
git clone <repo-url>
cd gamecorner-website
The project is purely static; no build step is required. Open index.html in a browser to view.

💡 Usage
Open index.html directly, or serve with a simple HTTP server for better local testing:
bash

# Using Python 3
python -m http.server 8000
Navigate to http://localhost:8000 in your browser.
Explore the site, customize styles in styles.css, and extend functionality in script.js.
🛠️ Development
Styling: Edit styles.css to adjust the design system. Use CSS variables for easy theme tweaks.
Interactivity: Modify script.js for additional UI behaviours.
Assets: Place images in the assets/ directory and reference them in HTML/CSS.
